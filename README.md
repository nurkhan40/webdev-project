🏢 CampusSync — Dormitory Management System
Created by: Nurkhan Kyrykbay, Dmitriy Ten.

📌 Project Description
CampusSync is a web application designed for students and dorm administrators to organize, manage, and streamline daily dormitory life. The platform allows residents to track kitchen duty schedules, report maintenance or cleanliness issues, post announcements for local dorm events or tournaments, and manage their campus living experience efficiently.

This project is built as a full-stack application using Angular (frontend) and Django + Django REST Framework (backend), with secure user authentication powered by JWT.
